# My First Repo

My First Repo is a simple starter HTML project created while learning Git and GitHub basics.

It contains a minimal webpage and can be used as a first step for practicing commits, repository setup, and static web hosting.

## Project Structure

```text
my-first-repo/
└── index.html
```

## What It Shows

- Basic HTML heading and paragraph content.
- A first GitHub project structure.
- A small foundation for learning repository workflow.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rs9313399-dot/my-first-repo.git
cd my-first-repo
```

Open `index.html` in any browser.

You can also serve it locally:

```bash
python -m http.server 3000
```

Then visit:

```text
http://localhost:3000
```
